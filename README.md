# Project Title
Coder Friendly Fiesta

## Overview
Coder Friendly Fiesta is a UI/UX design project implemented from Figma designs and wireframes. This repository contains the project structure, assets, and notes describing how the interface was designed and implemented.

## Design & Implementation
- Tools: Figma (high-fidelity designs & prototype), low-fidelity wireframes (initial layout & flows)
- Implementation approach:
  - Start with wireframes to define layout and user flows.
  - Iterate in Figma to produce high-fidelity screens and interactive prototypes.
  - Export assets and specs from Figma for development (icons, colors, spacing, typography, and exportable images).

## How wireframes and Figma were used
1. Wireframing
   - Created low-fidelity wireframes to establish content hierarchy and page flows.
   - Reviewed with stakeholders and iterated on layout.
2. High-fidelity design
   - Built screens in Figma using reusable components (buttons, inputs, cards).
   - Defined a design system: color tokens, typography, spacing scale.
3. Prototyping & Handoff
   - Built click-through prototypes for usability validation.
   - Generated specs and exported assets for developers.

- Use design tokens exported from Figma for consistent theming.

- Accessibility: ensure color contrast, keyboard navigation, and semantic markup match the design intent.
